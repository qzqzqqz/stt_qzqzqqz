# STT 在线音频转录网站 — 项目计划

> **创建日期:** 2026-04-22
> **技术栈:** FastAPI + Vue3 + PostgreSQL + Celery + Redis + mlx-audio

---

## 项目概览

基于 `transcribe_demo.py`（mlx-audio + VibeVoice-ASR）构建面向公众的在线转录网站。用户上传音频文件，系统进行带说话人分离和时间戳的转录，结果支持多种格式下载。
